# Production contract

The canonical skill lives inside the studio; a user-level directory junction points to it. The locator script prints the actual studio path even when invoked through the global skill. Run commands in that directory. For another project, port the brand and components deliberately rather than assuming the current working directory is a Remotion studio.

Read studio/BRAND.md for color/Arabic rules, MOTION_RULES.md for easing/timing/safe zones, DIRECTOR_BRIEF.md for directing, STORYBOARD_GUIDE.md and AUDIO_SYNC.md for narration alignment, QUALITY_CHECKLIST.md for evidence and revisions, EXPORT_STANDARDS.md for encoding/performance.

On Windows, studio.ps1 selects the verified user-local Node runtime. Commands:

    ./studio.ps1 dev
    ./studio.ps1 episode:new topic-slug
    ./studio.ps1 episode:validate topic-slug --draft
    ./studio.ps1 episode:validate topic-slug
    ./studio.ps1 episode:preview topic-slug
    ./studio.ps1 check
    ./studio.ps1 episode:render topic-slug
    ./studio.ps1 verify

An episode lives in episodes/<slug>: episode.json, script.ar.md, director-brief.md, storyboard.md, assets/{audio,images,sfx,music}, review/. No voiceover, scenes, or captions are invented by episode:new.

episode.json uses schemaVersion=1, language=ar-EG, status=draft|ready, objectives[], scriptFile, voiceover {file,durationMs,volume}, scenes[], captions[], sfx[], music|null, references[], render. Files are relative to the episode folder with forward slashes. Public assets and render props are generated by prepare/preview/render.

Scenes contain id,type,startMs,endMs,title,accent,visualIntent,spokenCue and type-specific data: description, steps (process), layers (neural), comparison.left/right. They cover the measured voiceover continuously. Caption[] entries contain text,startMs,endMs,timestampMs:null,confidence:null unless real measurements exist. Use complete short phrase cues for the provided ArabicCaption; token-level captions require checked phrase grouping before display. Overlapping or out-of-range cues fail validation.

Renderer uses full untrimmed voiceover and global millisecond captions. If editing narration, update the master timing and preserved source intentionally; no independent media trim should leave caption timing unchanged.

Do not mark draft data ready until listening and alignment checks are done. Schema validation confirms structure, not educational truth or spoken-word alignment. A silent technical render verifies the pipeline only.

Extend src/scenes/EpisodeScene.tsx and src/utils/episode-schema.ts together for new visual types. Reuse typography, motion and diagram primitives; keep specialized scenes explicit and reviewable. Use supplied local images via staticFile and image components that wait for loading.
